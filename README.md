# Dina Portfolio

## تشغيل الموقع
1. فك ضغط الملف.
2. افتح `index.html` في المتصفح.
3. لتعديل الألوان والتنسيق، افتح `style.css`.
4. لتعديل سلوك القائمة والوضع الليلي، افتح `script.js`.

## قبل النشر
- تأكدي من أن البريد الإلكتروني ورقم واتساب صحيحان ومخصصان للتواصل العام.
- أضيفي اسم التخصص والمؤسسة التعليمية إذا رغبتِ.
- المشاريع المعروضة موضحة كأفكار تدريبية وليست مشاريع مكتملة.
- مهارات HTML وCSS وJavaScript موضحة بأنها قيد التعلم، وليست خبرة احترافية.
